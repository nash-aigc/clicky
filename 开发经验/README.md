# 开发经验

这个文件夹记录 Clicky 改造成现在这个样子的全过程——**改了什么、为什么这么改、踩过哪些坑、哪些数字是实测出来的**。

它不是使用说明。想知道怎么装、怎么配，看仓库根目录的 `CLAUDE.md` 和 `README.md`。这里写的是「下一次再动这块代码时，你需要先知道什么」。

## 写这些文档时守的三条规矩

1. **数字必须带出处。** 每一处性能数字、每一个上限，都写清楚是**哪一天测的、用什么参数测的**。没测过的就写「推测」，不写成结论。
2. **坑要写根因，不是写现象。** 「光标关不掉」不是经验，「那个开关在界面上被注释掉了，所以 guard 永远为真」才是。
3. **只写这个仓库里真实存在的事实。** 代码里没有的 API、没跑过的流程，不写。

## 一句话概括这次改造

改造前是一个「贴 Claude 的 API Key 就能用」的演示项目，带 Cloudflare Worker 代理、PostHog 埋点和一堆写死的服务商。这次改造做的是三件事：**把服务商换成用户自己能配的**、**把上报用户内容的东西全删掉**、**把原本不可调的体验（光标、设置）变成可调的**。
