一张图看懂：Clicky 的大脑

只有一个大脑（AI）。它看得到你说的、你的屏幕、以及一张"我会做什么"的清单， 然后自己决定：直接回答你，还是动手去做。

你设计的那些 agent 去哪了？

没有消失，只是换了位置：从"主脑必须派人去找的独立助手"，变成"主脑手里的一件工具"。

  • 画图 agent（SVG） — 主脑说"这个要画图"，画图助手就去生成图形。你说话的时候看不到这个切换，只看到结果。
  • 执行 agent（脚本） — 主脑说"这个用脚本"，脚本就跑。今天常见的动作都已经写成脚本了。
  • Claude Code — 主脑自己反复搞不定时才叫，是外援，不是日常路径。

好处：你只需要理解"一个大脑 + 几件工具"。坏处：工具一多，那一页清单会变长——见下面。

什么时候才需要加一个"分诊台"

今天：清单十几条

全部给主脑看，它挑得动。不需要任何中间层—— 最简单、也是最快的做法。

将来：清单几百条

一页清单变成一本书，主脑每问一次都要背一遍：变慢、变贵、还容易挑错。 到那时在门口加一个"分诊台"，先挑出几条，再给主脑。

判断标准很简单：哪天你觉得它回答变慢、变贵、或者挑错动作了，再考虑加。在那之前不加。
