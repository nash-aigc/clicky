Wanna 归档 · 2026-09-24

整个框架：一条语音回路，四类分流，一个旁路

用户开口或打字 → 一条回复（说话 + 标签）→ 标签决定谁执行。 执行体里有循环的只有主控和 Claude Code（后者仅两条入口：UI 切换器 / 转写提到 claude·cloud·cc，模型永不自主派发）；复盘不接请求，固化「反复手动做的事」。

四道闸门与四个模型角色

闸门（互相独立）
  • 允许 Wanna 操作电脑 —— 点击 / 滚动
  • 允许打字和按快捷键
  • 文件访问清单 —— 逐路径、读/写分开
  • 允许调用工具库 —— 独立总闸
  • 允许 Agent 后台任务 —— Claude Code
  • 复盘启用 —— 默认停用
模型角色（每个可独立配 URL / key / 模型）
  • 👂 转写 —— 流式 ASR
  • 🧠 视觉 —— 看屏幕 + 决策 + 分流
  • 👄 播报 —— TTS
  • 🔍 复盘 —— 离线批处理（默认手动）
  • 画图助手 / 工具提炼 —— 自带的小模型调用，不在四角色里
真 agent 只有三个
  • 主控循环（看结果、有循环）
  • Claude Code（仅两条入口：UI / 转写关键词；模型不自主派发）
  • 复盘（旁路、按时间醒）
  • 画图助手 / 脚本 —— 有模型调用但无决策循环，不算 agent
蓝色 = 主链路 · 紫色 = 复盘旁路 · 绿色 = 成功/生效路径 · 橙色 = 红线。 详细依据：解决方案/04-Agent体系/（主控循环Agent 01–07、复盘Agent README/02/03、图形讲解子目录）。 全部为设计，除语音回路与四类分流骨架外均未实施。
