# 02 · 主 agent

> 主 agent 是**唯一的大脑**。它的提示词里**只有四样东西**，因为其余全被移进了 sub agent。
> 定稿 2026-09-25。

---

## 一、提示词里的四样（仅此四样）

| 槽 | 内容 | 今天的状态 |
|---|---|---|
| ① 屏幕 | 截图，多屏时每块屏一张（JPEG → base64 进 `image_url`） | **已有**（`CompanionManager.swift:2173`） |
| ② 用户的话 | 原话 + 可选的数据块 | **已有** |
| ③ 历史 | 最近若干轮真实对话 + 压缩摘要 | **已有** |
| ④ sub agent 目录 | 「什么时候叫图形 / 执行 / 文本」各一两句 | **要写**（见 §三） |

**没有第五样。** 今天那份 22,954 字符的提示词要按下面的方式拆掉。

## 二、从今天的提示词里移走了什么（移走，不是删掉）

实测分节大小（`CompanionManager.swift:1725`，共 22,954 字符）：

| 今天的分节 | 字符 | 搬到哪 |
|---|---|---|
| `rules:`（通用规则：语言、长度、语气…） | 3,249 | **留在主 agent**（这是"怎么跟人说话"，每个人都用） |
| `examples:` + `format:` | ~2,700 | **留在主 agent** |
| `element pointing:`（怎么指位置） | 1,927 | → **图形 agent** 的技能 |
| `drawing on screen:` + `kinds:` | 1,355 | → **图形 agent** 的技能 |
| `the user can mark the screen themselves:` | 945 | → **图形 agent** 的技能 |
| **`operating the computer:`（全部动作说明）** | **12,096** | → **执行 agent** 的技能 |
| 补充指令 / 回答长度（`companionSystemPrompt(for:)`，`:1862`） | 用户自己写的 | **留在主 agent** |

**搬完之后主 agent 提示词 ≈ 4,000–6,000 字符**（今天 22,954），
省下的部分正是"对屏幕提问"这条高频路每问一次都在白付的钱。

## 三、sub agent 目录怎么写（唯一需要新写的部分）

目录只回答**"什么时候叫谁"**，不回答"怎么做"。每条一两行，形如：

```
你手边有三个助手，需要时用 [AGENT:名字] 叫它们；能自己回答的就自己回答。

图形 — 用户要在屏幕上看到指示或图形时（指位置、圈出某处、画流程图、画示意图）。
       它负责画，你不需要描述怎么画。

执行 — 用户要让电脑真的动起来时（点击、打字、开 App、调音量亮度、读写文件、跑脚本）。
       你说做什么，它去做，做完会把结果给你。

文本 — 用户要一段长内容、或需要某个专业场景的写法时（文章、报告、翻译、
       销售/法律/财务/建筑等场景的文案）。它没有任何工具，只产出文字。
```

**为什么不写细**：目录太粗 → 主 agent 选错 agent；太细 → 又长回今天的胖提示词。
这条粗细是**唯一需要实测调的地方**（[09](09-施工顺序与验收.md) 里列为要验的一项）。

## 四、主 agent 自己回答 vs 交给 sub agent

| 情况 | 谁来做 | 为什么 |
|---|---|---|
| 「屏幕上这句话什么意思」「这是什么东西」 | **主 agent 自己答** | 看一眼就能说，交出去反而慢 |
| 「圈一下这个按钮」 | 图形 agent | 主 agent 不管坐标 |
| 「帮我点登录」 | 执行 agent | 动手的事归它 |
| 「写一篇关于…的文章」 | 文本 agent | 长内容 + 场景方法论归它 |
| 说不清 | **主 agent 自己答**（最安全） | 答错只是一句不好听的话；派错会动手 |

**风险不对称**是这条表的原则：**宁可自己答错，不可派错活。**

## 五、它能看到的与看不到的

| 看得到 | 看不到（这些在 sub agent 里） |
|---|---|
| 屏幕截图 | 坐标怎么算、图形怎么排版 |
| 用户的话 + 历史 | 动作标签怎么写、脚本怎么调、MCP 参数 |
| sub agent 的**名字和用途** | 技能正文（用到才展开） |
| 执行结果（数据块） | 具体实现细节 |
