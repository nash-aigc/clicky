# 08 · 复盘与高速通道

> 复盘 agent 是**唯一不接用户请求**的执行体：它按时间自己醒过来，读历史，
> 统计出"哪些需求反复出现"，然后**把其中最高频的几个变成高速通道的一行入口**。
> 定稿 2026-09-25。详细规格见 [`08a-高频统计与高速通道.md`](08a-高频统计与高速通道.md)
> 与 [`细节/复盘-总纲.md`](细节/复盘-总纲.md)、[`细节/03-触发与日志导出.md`](细节/03-触发与日志导出.md)、
> [`细节/02-界面与审批.md`](细节/02-界面与审批.md)。

## 一、它在整个架构里的位置

```
主 agent + 三个 sub agent  ← 标准通道（完备，慢一点）
        ▲
        │ 没命中 / 执行失败就落回来
        │
高速通道（提示词里 ≤20 行入口）← 只有复盘能往这里加东西
        ▲
        │ 统计：某类需求反复出现
        │
    复盘 agent（旁路，不接用户请求）
```

**它是建造者，不是执行者**：它不替用户做事，它决定"哪些事以后可以更快"。

## 二、它统计什么

读用户**全部历史任务**（turn 记录里已有：用户说了什么、执行了什么、耗时、是否被打断），
按「**大类 → 小类**」两级统计：

| 大类 | 小类 | 次数 | 首/末次 | 跨天数 | 处置 |
|---|---|---|---|---|---|
| 系统控制 | 调音量到指定值 | 23 | 09-03 / 09-24 | 12 天 | **已进高速通道** |
| 内容生成 | 把选中的话翻成英文 | 11 | 09-05 / 09-24 | 11 天 | **已进高速通道** |
| 屏幕标注 | 圈出某个元素 | 6 | 09-12 / 09-22 | 6 天 | 候选（属于图形 agent，不快通道） |

**统计单位是"任务类型"，不是句子**——换个说法做同一件事算同一类。

## 三、什么算"高频"（三条同时满足）

| 规则 | 值 | 为什么 |
|---|---|---|
| 次数 | **> 5 次** | 用户定的 |
| 跨越天数 | **≥ 3 个不同日期** | 防"一个下午连说五遍"被当成长期高频 |
| 新鲜度 | **最近 30 天内出现过** | 半年不用了的不该占位置 |

不满足 → 留在表里继续观察，**什么都不做**（这是默认结果）。

## 四、晋级成什么（四种形态，从轻到重）

| 形态 | 写进提示词的东西 | 适合 |
|---|---|---|
| ① 一行提示词 | "用户说『静音』→ 执行 mute" | 无参数、说法固定 |
| ② 脚本路径 | "高频操作：调音量（脚本 …）" | 有脚本，参数现生成 |
| ③ 脚本 + 参数 | "用户说『音量调到 N』→ 执行 …，N 从话里取" | 参数明确、模式固定 |
| ④ 工具 / MCP 工具 | "遇到 X 用工具 Y" | 第三方能力 |

**四种的共同点**：写进去的都是**"一眼能认出的入口"**，不是能力本身。
能力仍旧住在工具库/技能里，提示词里只有一行索引。

## 五、三条铁律

### 5.1 预算上限：20 行 / 约 800 字符

我们刚把 12,096 字符的动作说明搬出提示词，高速通道又在往里加东西——
**不设上限，半年后提示词会重新长胖**。

| 规矩 | 值 |
|---|---|
| 高速通道路段总预算 | **≤ 20 行 / 约 800 字符** |
| 超了怎么办 | **按频率淘汰**最低的（只撤提示词那一行，脚本不删） |
| 长期不用 | **60 天没命中 → 自动撤出**，回到观察表 |

### 5.2 必须用户批准

写进提示词 = 给主 agent 一条**长期指令**。一条统计错的条目不是"没用"，
而是**每次遇到都会被错误地执行**。所以进待审区，用户批准才生效；拒绝的移到 `已拒绝/`，不删除。

### 5.3 只写"入口"，不写"怎么做"

那一行只回答"这事该用哪个脚本/哪条路"。具体做法仍住在 sub agent 的技能里——
否则就是用另一种方式把提示词重新吹胖。

## 六、复盘自己的触发、水位与权限

| 项 | 设计 | 细节 |
|---|---|---|
| 触发 | **手动（默认）/ 每 50 个任务自动 / 定时** | [`细节/复盘-总纲.md`](细节/复盘-总纲.md) §六 |
| 不重复 | 每个 turn 打 `reviewedAt`；只处理没打过的 | 同上 |
| 不看正在聊的 | `turnFinishedAt < now − 10 分钟` 才进 | 同上 |
| 崩了怎么办 | 水位只在整批处理完后推进 → 不重不漏 | 同上 |
| 产出权限 | **只能新增与追加，禁止删除与覆盖**；三级（低/中/高）进待审区 | 同上 §八 |
| 它的工具 | **只有两个**：AnySearch（搜索）+ 写入（锁死在指定子文件夹） | 同上 §八 |
| 会话导出 | 导出与复盘**分开**：导出廉价、默认自动；复盘昂贵、默认手动 | [`细节/03`](细节/03-触发与日志导出.md) |

## 七、验收

| # | 判据 |
|---|---|
| H1 | 统计表按「大类 → 小类」两级呈现，每行有次数、首末时间、跨天数 |
| H2 | 同一天说 5 次 → **不晋级**（未跨 3 天） |
| H3 | 跨 10 天说了 6 次 → 进候选 + 出现在待审区 |
| H4 | 未批准的候选**没有**进入系统提示词（对比提示词字符数） |
| H5 | 晋级条目在提示词里只占一行，**不含**具体步骤 |
| H6 | 高速通道命中时**不进**主 agent 循环（日志可验证） |
| H7 | 高速通道执行失败 → **落回标准通道**并完成任务 |
| H8 | 超预算 → 按频率淘汰最低一条，留记录 |
| H9 | 60 天未命中 → 自动撤出（脚本保留） |
| H10 | 撤出后再用起来 → **能重新晋级**（不是单行道） |
